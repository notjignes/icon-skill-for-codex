# Waterlemon UC object style

This is a visual guide for object generation and base edits. Use the main skill for routing, reference selection and export. Character wardrobe and treatment belong to `skeuo-uc-characters.md`.

## Visual language

Create premium tactile miniature 3D objects between product rendering and iconography: tangible, calm and immediately recognisable in a UI grid. Preserve real material identity while simplifying for the screen.

- **Materials:** mostly matte-to-satin; controlled gloss for glass, polished metal or ceramic when identity requires it. Wood is smooth and lightly finished, fabric plush but simplified, metal clean, plastic moulded, glass/liquid readable. Use low-to-moderate texture density; avoid heavy grain, mirror chrome everywhere, noisy reflections, grime and wear.
- **Form:** keep the primary silhouette, major functional parts and clear material separation. Reduce tiny seams, engravings, buttons and decorative complexity. Soften edges with subtle bevels. Slightly thicken fragile parts when needed for small-scale legibility.
- **Palette:** derive one dominant colour family and limited accents from the object's materials. Keep clean colour blocks, moderate saturation and selective brighter accents for recognition. Avoid muddy neutrals or arbitrary multicolour fragmentation.
- **Lighting:** soft front-biased studio light, gentle contrast and broad premium highlights. Request no cast, drop, contact or floor shadow for new objects. Preserve existing shadows in base edits; never force an added shadow.
- **Composition:** single centred object, full frame and comfortable 4:3 margins. Object plus service cue permits at most two masses; the cue stays secondary and both read as one icon. No scenes, rooms, tabletops, hands or people.
- **Camera:** preserve selected base orientation. For new objects, use the planned view: normally straight front, or level side-horizontal for wide/long silhouettes. Avoid exaggerated perspective and top-down views unless explicitly requested. User composition/framing instructions override defaults.

No readable text, logos, branding, watermarks or barcodes. Avoid catalogue photography, cinematic drama, excessive manufacturing detail, toy/cartoon exaggeration and flat vector styling. Never add faces, limbs or mascot features to objects.

## Prompt supplement

Add only the relevant details above when attached references do not communicate them. Always specify subject and requested change. For edits, identify the base and preserve untouched geometry, materials, framing and lighting.

Request solid `#f5f5f5` during generation unless the user chooses another background. Final output is `1024x768` PNG. Export proportionally contains the whole source frame and composites existing alpha; it never performs background cleanup, threshold segmentation, shadow removal or colour-based cropping. Background removal remains manual post-processing. Keep light, material finish, simplification and optical size coherent across a set.

## Category meaning and inspiration

Choose one recognizable primary product/item for the service. Add one secondary tool/item only when it resolves category ambiguity, and keep it visually subordinate. For example, a dedicated upholstery extractor can communicate upholstery cleaning alone; a tap plus a wrench clarifies repair. Avoid unrelated decorative props. The user identifies Airbnb skeuomorphic iconography as inspiration, translated through the UC archive into tactile miniature objects; this does not authorize importing external references or changing preserved base geometry.
